Privacy

Website & IP scans

A scan's results are not stored unless you choose to share them. Ticking "Create a shareable link" saves that one report behind an unguessable link that expires (you get a private delete link). Monitoring, where available, keeps your scan history until you stop it. Nothing else about a scan is kept.

Code scans

Uploaded files are processed in memory and then discarded — they are never written to disk or stored. Only package names and versions are sent to OSV.dev to look up known vulnerabilities. Any secrets found in your code are masked before they appear in the report.

What reaches third parties

  • OSV.dev — dependency names and versions, for vulnerability lookups.
  • crt.sh — the domain you scan, to read certificate-transparency logs for subdomains.
  • A reverse-IP provider (only if the operator has configured one) — the IP you scan.

Photos, file contents and scan findings are never sent anywhere beyond what's listed above.

Logs & rate limiting

Like any web service, the server records basic request logs (including the visitor IP) for rate limiting and abuse prevention. These are not linked to scan results.

Email (monitoring)

If you set up monitoring, your email address is stored so we can send alerts, and only for that. Every email has a one-click unsubscribe, and stopping monitoring deletes the address and the scan history.
