# Security policy

riskscope is a security tool, so bugs in it matter twice. If you find a vulnerability in riskscope itself
(for example a way to make the hosted scanner reach internal addresses, bypass ownership verification, or
read another user's results), please report it privately through
[GitHub private vulnerability reporting](https://github.com/alifjegham-wq/riskscope/security/advisories/new)
rather than opening a public issue.

We aim to acknowledge reports within 3 days.
